# 📚 Encantos Literários

Página desenvolvida como projeto do curso Fullstack da Rocketseat, com o objetivo de treinar a construção de uma interface a partir de um layout disponibilizado no Figma.

> ⚠️ Este projeto foi feito **apenas para fins de estudo**.

🔗 **Demonstração:** https://cristiandelima.github.io/Encantos-literarios/

## 🚀 Tecnologias utilizadas

- **HTML5** — estruturação semântica do conteúdo
- **CSS3** — estilização, layout responsivo

## 📁 Estrutura do projeto

```
Encantos-literarios/
├── assets/       # imagens e demais recursos visuais
├── styles/       # arquivos de estilização (CSS)
└── index.html    # estrutura principal da página
```

## 💻 Como executar

Clone o repositório e abra o arquivo `index.html` no navegador:

```bash
git clone https://github.com/CristianDeLima/Encantos-literarios.git
cd Encantos-literarios
```

Depois é só abrir o `index.html` direto no navegador ou usar uma extensão como o **Live Server** (VS Code) para visualizar com recarregamento automático.

## 🎯 Objetivo

Praticar a criação de páginas web responsivas e fiéis a um layout, aplicando boas práticas de HTML semântico e organização de CSS.
